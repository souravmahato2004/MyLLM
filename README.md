# GPT From Scratch

A complete end-to-end implementation of a GPT-style language model built from scratch. This project follows the entire LLM development pipeline—from tokenization and model training to inference, backend APIs, and a web interface.

## Project Structure

```text
gpt-from-scratch/
├── model/        # GPT architecture and training
├── inference/    # Model inference and generation
├── backend/      # API for serving the model
├── frontend/     # Web interface
└── README.md
```

## What's Inside

* GPT implementation in PyTorch
* Byte Pair Encoding (BPE) tokenization
* Custom datasets and dataloaders
* Transformer architecture
* Model training
* Text generation
* Inference pipeline
* Backend API
* Frontend application

## Tech Stack

* Python
* PyTorch
* FastAPI
* React / Next.js
* Docker

## Goal

The goal of this project is to understand how modern GPT-style language models work by implementing every major component from scratch and building a complete application around them.
